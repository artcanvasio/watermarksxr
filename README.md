# WatermarksXR

Mixed-reality souvenir of Augsburg’s water heritage: scan one of the four landmark drawings on the water-wheel souvenir and the landmark appears on top of it.

Live: https://watermarks.artcanvas.io

Static site (no build step): `index.html`, `app.js` (screens), `ar.js` (MindAR image tracking + three.js overlays), `targets/targets.mind` (compiled panel targets), `sw.js` (offline cache). Add `?dev=1` to the URL for the recognition simulator.
